A personal automation tool. Single user. Not a commercial service.

What this application does

This is a private, single-user automation tool.

これは個人が自分ひとりで使う自動化ツールです。

Who can use it

Only the owner of this application. There is no sign-up, no user account system, and no way for anyone else to use it. It is not offered to the public.

利用者は作者本人のみです。登録機能もアカウント機能もなく、第三者が利用する手段はありません。

Google account access

The application requests a single, narrowly scoped permission:

  • https://www.googleapis.com/auth/drive.file — per-file access, limited to files and folders that this application itself creates.

It cannot see, read, or modify any other file in the owner's Google Drive.

要求する権限は drive.file のみです。これはこのアプリ自身が作成した ファイルとフォルダにしかアクセスできないスコープで、Drive 内の他のファイルを 閲覧・変更することはできません。
