Privacy Policy

Privacy Policy · Last updated: 2 September 2026

1. Summary

This application is a private tool used by one person: its owner. It does not collect, store, transmit, sell, or share personal data belonging to anyone. It has no users other than its owner, no servers of its own, and no analytics.

本アプリは作者本人だけが使う個人用ツールです。他者の個人情報を収集・保存・送信・販売・共有 することは一切ありません。作者以外の利用者は存在せず、独自のサーバーも解析ツールも持ちません。

2. What the application accesses

With the owner's explicit consent, the application uses one Google OAuth scope:

  • https://www.googleapis.com/auth/drive.file

This scope grants per-file access. The application can only create files and folders in the owner's Google Drive, and can only read or modify files it created itself. It cannot access any other content in Google Drive.

使用するスコープは drive.file の 1 つだけです。これはアプリ自身が作成した ファイル・フォルダのみを対象とする権限で、Drive 内の他のデータには一切アクセスできません。

3. What data is handled

The only data uploaded is PDF documents generated from the owner's own market-analysis notes. These documents contain publicly available market figures and the owner's own written commentary. They contain no personal data about any third party.

アップロードされるのは、作者自身が書いた市況レポートを PDF 化したものだけです。内容は 公開されている市場データと作者自身の記述であり、第三者の個人情報は含まれません。

4. Where data goes

PDF files are uploaded directly from the owner's execution environment to the owner's own Google Drive account, over HTTPS. No copy is sent anywhere else. There is no third-party processor, no intermediate server, and no external database.

PDF は作者の実行環境から作者自身の Google Drive へ HTTPS で直接送られます。他のどこにも 複製は送られず、第三者の処理業者・中継サーバー・外部データベースは介在しません。

5. Credentials

OAuth credentials (client ID, client secret, refresh token) are stored only as environment variables in the owner's private execution environment. They are never written into any source repository and are never shared.

OAuth の認証情報（クライアント ID・シークレット・リフレッシュトークン）は、作者の実行環境の 環境変数としてのみ保持します。ソースリポジトリには書き込まず、外部に共有もしません。

6. Retention and deletion

Uploaded PDF files remain in the owner's Google Drive until the owner deletes them, and are under the owner's sole control. The owner can revoke this application's access at any time at myaccount.google.com/permissions, which immediately and permanently ends all access.

アップロードされた PDF は作者が削除するまで作者の Drive に残り、管理権限は作者のみが持ちます。 アクセス権は Google アカウントの権限設定 からいつでも取り消せ、取り消した時点でアクセスは完全に終了します。

7. Limited Use

This application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Data obtained through Google APIs is not used for advertising, is not sold, and is not transferred to any third party.

Google API から得た情報の取り扱いは、Limited Use 要件を含む Google API Services User Data Policy に準拠します。広告利用・販売・第三者提供は行いません。
